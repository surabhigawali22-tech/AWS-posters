AWS SBG QR CAMPAIGN - quick start
1. Upload ALL files in this folder to a public GitHub repo (see chat for steps), turn on Pages.
2. Open config.js, set BASE_URL to https://USERNAME.github.io/REPO  (no trailing slash), upload again.
3. Open BASE_URL/index.html -> QR dashboard -> DOWNLOAD QR for each poster.
4. Scan every QR with a phone on MOBILE DATA before printing.
Edit all text/clues in config.js. The dashboard needs internet (loads a QR library from cdnjs).
